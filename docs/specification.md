# ポーカー 仕様書

最終更新: 2026-06-23

---

## 1. 概要

| 項目 | 内容 |
|------|------|
| ゲーム名 | ポーカー (Poker) ※5カードドロー |
| ジャンル | カードゲーム |
| プラットフォーム | Web（ブラウザ） |
| 言語 / FW | Dart / Flutter 3.29 |
| 対戦形式 | あなた1人 vs CPU1体 |
| 外部ライブラリ | なし（Flutter標準のみ） |

5枚配られた手札からカードを交換して役を作り、CPUと役の強さで勝負します。
全5戦を終えたあと、所持チップの多いほうが勝者です。

---

## 2. 画面構成

```
┌──────────────────────┐
│      第 1 戦 / 全 5 戦       │ ← 上部：ラウンド表示
│        🂠 🂠 🂠 🂠 🂠       │ ← CPUの手札（裏向き）
│   CPU 💰100 賭け20           │
│                          │
│        💰 POT 40           │ ← 中央：ポット（掛け金合計）
│                          │
│   あなた 💰100 賭け20         │
│        🂡 🂮 🃅 🃞 🂨       │ ← あなたの手札（表向き／選択可）
│ ┌──────────────────┐ │
│ │ BET / CHANGE / SHOWDOWN│ │ ← 操作パネル（フェーズで変化）
│ └──────────────────┘ │
└──────────────────────┘
```

- 背景：緑のフェルト＋楕円の卓枠（`TablePainter` が描画）
- 上：CPU（手札は裏向き）／中央：ポット／下：あなた（手札は表向き）
- 各座席：名前・所持チップ(💰)・ベット額・役（ショーダウン後）・勝敗バッジ
- 横並びで幅が足りないときは `FittedBox` で自動縮小（はみ出し防止）
- 開始前／決着後は半透明オーバーレイ（タイトル＋ボタン）を重ねる

## 3. 操作仕様

| フェーズ | 操作 | 動作 |
|------|------|------|
| BET | ＋ / − ボタン | 掛け金を10刻みで増減 |
| BET | 「BET」ボタン | 掛け金を確定してカードを配る |
| CHANGE | 手札カードをタップ | 交換するカードを選ぶ／外す（金枠で浮く） |
| CHANGE | 「CHANGE」ボタン | 選んだカードを交換（0枚ならそのまま） |
| SHOWDOWN | 「SHOWDOWN」ボタン | CPUの手札を公開して勝敗判定 |
| 結果 | 「次の戦へ」 | 次ラウンド／最終結果へ |

- **Enterキー**でも、その時の主ボタン（BET/CHANGE/SHOWDOWN/次へ/Start）を実行できます。
- CPUの交換は自動（クリック不要）。

## 4. ルール仕様

| 項目 | 内容 |
|------|------|
| 戦数 | 全 5 戦（`totalRounds`） |
| 開始チップ | 各自 100（`startChips`） |
| 配り方 | 各自5枚（あなたは表向き、CPUは裏向き） |
| カード交換 | 0〜5枚を1回だけ交換できる |
| 役の強さ | 下記「役一覧」を参照。同じ役は構成カード→キッカーで数字比較 |
| 引き分け | 役・数字が完全に同じなら引き分け（掛け金は返還） |
| ベット | **同額ポット方式**：あなたが掛け金 B → CPU も同額 B → ポット=2B |
| 精算 | 勝者がポット獲得（実質 勝ち+B／負け−B／引き分け0） |
| 掛け金上限 | なし（持ち点を超えて賭け可。負けるとマイナスもあり得る） |
| 最終勝敗 | 5戦後、所持チップの多いほうが勝ち（同点は引き分け） |

### 役一覧（強い順）

1. ロイヤルストレートフラッシュ
2. ストレートフラッシュ
3. フォーカード
4. フルハウス
5. フラッシュ
6. ストレート（A-2-3-4-5 の「ホイール」も成立、最高位は5扱い）
7. スリーカード
8. ツーペア
9. ワンペア
10. ハイカード

> エースは通常もっとも強い（14）として扱い、ホイール（A-2-3-4-5）の
> ときだけ 1 として扱います。

## 5. ゲーム状態（GamePhase）

| 状態 | 説明 | 画面 |
|------|------|------|
| `ready` | 開始前 | スタートオーバーレイ |
| `betting` | 掛け金選択 | ＋／−と「BET」 |
| `playerDraw` | 交換するカード選択 | 「CHANGE」 |
| `cpuDraw` | CPUが交換中（自動） | 「CPUが交換しています…」 |
| `showdownReady` | 勝負待ち | 「SHOWDOWN」 |
| `roundResult` | このラウンドの結果 | 役・勝敗表示＋「次の戦へ」 |
| `gameOver` | 5戦終了 | 結果オーバーレイ＋「Restart」 |

遷移:
`ready` →(Start)→ `betting` →(BET)→ `playerDraw` →(CHANGE)→
`cpuDraw` →(自動)→ `showdownReady` →(SHOWDOWN)→ `roundResult`
→(次の戦)→ `betting`（5戦目まで）→ `gameOver` →(Restart)→ `betting`

## 6. 役判定・CPU AI（`lib/game/poker_logic.dart`）

### 役判定（HandEvaluator.evaluate）
- 5枚の数字を数え、ペア構成・フラッシュ・ストレートを調べて役を決定
- 比較用に `tiebreak`（強い順の数字配列）を返し、`compareHands` で
  役→構成カード→キッカーの順に比較する

### CPU交換AI（CpuAi.cardsToExchange）
- 完成役（ストレート以上・フルハウス・フラッシュ）はキープ（交換0枚）
- フォーカード→1枚／スリーカード→2枚／ツーペア→1枚／ワンペア→3枚交換
- 役なし（ハイカード）は一番強い1枚を残して4枚交換

## 7. 主なパラメータ（調整値）

`lib/game/game_screen.dart` の定数で定義。

| パラメータ | 値 | 意味 |
|------------|----|------|
| `totalRounds` | 5 | 戦数 |
| `startChips` | 100 | 開始チップ |
| `betStep` | 10 | 掛け金の刻み |
| `minBet` | 10 | 最低掛け金 |
| `handSize` | 5 | 配る枚数 |
| 自動進行の待ち時間 | 0.7秒 | CPU交換の演出の間 |
