# ポーカー 遊び方

## 起動方法

| 方法 | 手順 |
|------|------|
| かんたん | `run.bat` をダブルクリック（Chromeで起動。初回はビルドに少し時間がかかります） |
| コマンド | プロジェクトフォルダで `flutter run -d chrome` を実行 |

起動中のターミナルでは以下のキーが使えます。

| キー | 動作 |
|------|------|
| `r` | ホットリロード（コード変更の即時反映） |
| `R` | ホットリスタート（状態を初期化して再反映） |
| `q` | 終了 |

---

## ゲームの目的

- 5枚の手札からカードを交換し、**強い役**を作ってCPUと勝負します。
- 役が強いほうがそのラウンドの勝者で、**ポット（掛け金の合計）**を獲得します。
- **全5戦**を終えたとき、**所持チップが多いほうが勝者**です。

---

## 役の強さ（強い順）

| 役 | 内容 |
|----|------|
| ロイヤルストレートフラッシュ | 同じマークの 10・J・Q・K・A |
| ストレートフラッシュ | 同じマークの連番5枚 |
| フォーカード | 同じ数字が4枚 |
| フルハウス | 3枚＋2枚（スリーカード＋ワンペア） |
| フラッシュ | 同じマーク5枚 |
| ストレート | 連番5枚（A-2-3-4-5 もOK） |
| スリーカード | 同じ数字が3枚 |
| ツーペア | ペアが2組 |
| ワンペア | 同じ数字が2枚 |
| ハイカード | 上記いずれもなし（一番強い数字で勝負） |

> 同じ役どうしは、役を構成するカード → 残りのカード（キッカー）の順に
> 数字を比べます。それでも同じなら引き分け（掛け金は返還）。

## 画面の見方

```
┌──────────────────────┐
│     第 1 戦 / 全 5 戦       │ ← 今が何戦目か
│       🂠 🂠 🂠 🂠 🂠      │ ← CPUの手札（裏向き）
│  CPU 💰100 賭け20          │
│        💰 POT 40          │ ← ポット（賭け金の合計）
│  あなた 💰100 賭け20        │
│       🂡 🂮 🃅 🃞 🂨      │ ← あなたの手札（表向き）
│   BET / CHANGE / SHOWDOWN  │ ← 操作ボタン
└──────────────────────┘
```

- 💰 … 所持チップ
- POT … その勝負での賭け金の合計（勝者が獲得）
- CPUの手札は SHOWDOWN まで裏向きです。

---

## 遊びの流れ

1. スタート画面で **「Start Game」** を押す
2. **BET**：＋／− で掛け金を決め、「BET」を押すとカードが5枚配られます
   （CPUも同額を出してポットになります）
3. **CHANGE（交換）**：
   - 交換したいカードを **タップ**して選ぶ（金色の枠で少し浮きます）
   - もう一度タップで選択解除
   - 「CHANGE」を押すと選んだカードを引き直します（**0枚ならそのまま**）
4. **CPUが自動で交換** します
5. **SHOWDOWN（勝負）**：押すとCPUの手札が公開され、役で勝敗が決まります
   - 勝ち → ポットを獲得（掛け金ぶん増える）
   - 負け → 掛け金ぶん減る
   - 引き分け（PUSH） → 増減なし
6. 「次の戦へ」で次のラウンドへ。**5戦終わると最終結果**が出ます
7. **「Restart」** で何度でも再戦できます

> **Enterキー**でも、その時の主ボタン（BET / CHANGE / SHOWDOWN / 次へ）を押せます。

---

## ちょいテク

- ペアがあるときは、ペアを残して他を交換すると役が伸びやすいです。
- 掛け金は**持ち点を超えても賭けられます**（負けるとマイナスに）。
  最終戦で逆転を狙う大勝負も可能です。
- 何も役がないときは、一番強いカードだけ残して4枚交換するのが基本です。
