# ゲーム名

**ポーカー（Poker）**

## ジャンル

カードゲーム

## 操作

- プレイヤーが掛け金を選択
    
- 「ベット」「交換するカードを選択」「勝負（Showdown）」をクリックまたはエンターキーで操作
    
- カード交換時は交換したいカードをクリックして選択
    

## 勝利条件

- 役の強いプレイヤーがそのラウンドの勝者となる
    
- 獲得したチップ数を5戦終了時に比較し、最終的に持ち点（所持チップ）が多いプレイヤーの勝利
    

## 基本ルール

- ゲーム開始時にプレイヤーとCPUへ5枚ずつカードを配る
    
- プレイヤーは任意の枚数のカードを交換できる
    
- CPUも簡単なAIによってカード交換を行う
    
- カード交換後、役を判定して勝敗を決定する
    
- 同じ役の場合は役を構成するカードの数字を比較する
    
- それでも同じ場合は引き分けとなり、掛け金は返還される
    
- 全5ラウンド実施する
    

## 役一覧（強い順）

1. ロイヤルストレートフラッシュ
    
2. ストレートフラッシュ
    
3. フォーカード
    
4. フルハウス
    
5. フラッシュ
    
6. ストレート
    
7. スリーカード
    
8. ツーペア
    
9. ワンペア
    
10. ハイカード
    

## 実装要素

- 物理演算（カード配布・カードめくり）
    
- CPU対戦AI
    
- ベットシステム
    
- 役判定システム
    
- スコア・チップ管理システム
